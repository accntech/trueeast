# Repository Instructions

## Git commits

- Use Conventional Commits for every commit message: `<type>(<optional-scope>): <imperative summary>`.
- Use an appropriate type such as `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, or `revert`.
- Keep the summary concise, lowercase, and free of a trailing period.
- Mark breaking changes with `!` before the colon and explain them in a `BREAKING CHANGE:` footer.
- Keep related changes together and separate unrelated concerns into logical commits.
